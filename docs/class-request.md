# 클래스 추가 요청 안내

GaugeOverlay에서 아직 지원하지 않는 클래스나 직업각인을 추가하려면, 그 클래스를 플레이하는 분의 스크린샷과 설명이 필요합니다. 지금 어느 클래스가 어디까지 지원되는지는 README의 **지원 클래스** 표에서 볼 수 있습니다.

추가는 세 단계로 나뉘며, 준비된 단계부터 하나씩 추가됩니다. 전부 한 번에 보내지 않아도 됩니다. 언제 추가되는지는 약속드리기 어렵습니다.

| 단계 | 추가되는 기능 | 필요한 것 |
|---|---|---|
| 1. 직업각인 감지 | 스킬창 맞추기 때 직업각인을 자동으로 알아봄 | 스킬 창 스크린샷, 질문 2·7 |
| 2. 아덴 게이지 | 오버레이 위쪽의 아덴 게이지 막대 | 게이지 빈 화면·가득 찬 화면, 질문 3 |
| 3. 아덴 스킬 | 아덴 스킬 칸, 사용 가능 표시, 게이지 빛남 | 플레이 영상, 질문 1·4·5·6 |

## 준비물

직업각인마다 따로 준비해 주세요. 두 직업각인을 모두 하시면 두 벌, 하나만 하시면 한 벌이면 됩니다.

**1. 스킬 창 스크린샷 (1단계)**
- 스킬 창(K)을 열어 **초각성 스킬 아이콘**이 보이게 찍어 주세요.
- 직업각인마다 아이콘이 다르니, 직업각인마다 한 장씩 필요합니다.

**2. 아덴 게이지 스크린샷 2장 (2단계)**
- 게이지가 **완전히 빈 화면** 1장, **가득 찬 화면** 1장.
- 두 장은 같은 자리에서, 게이지 말고는 바뀌는 것이 없게 찍어 주세요.
- **수련장**에서 재사용 대기시간을 초기화해 **모든 스킬이 준비된 상태**로 찍어 주세요. 앱이 스킬창 위치를 찾는 데 필요합니다.
- 화면 전체를 찍어 주세요. 스킬창과 아덴 게이지가 다 보여야 합니다.

**3. 플레이 영상 (3단계)**
- 직업각인마다 30–60초 정도.
- 아덴 스킬을 쓰면서 게이지가 차고, 빛나고, 줄어드는 모습이 보이면 됩니다.
- 해상도는 상관없습니다.

## 찍을 때 주의할 점

- 해상도, 21:9, HUD 크기는 아무것이나 괜찮습니다. 대신 쓰신 **해상도와 HUD 크기**(게임 설정의 HUD 크기 %)를 적어 주세요.
- **원본 PNG 파일**로 보내 주세요. 카카오톡·디스코드로 보내면 사진이 압축되어 쓸 수 없는 경우가 많습니다. 게임의 스크린샷 기능(PrtSc)이나 Windows 캡처 도구로 찍은 파일 그대로면 됩니다.
- 영상은 OBS, 지포스 익스피리언스, Windows 게임 바(Win+G) 등 무엇으로 녹화해도 됩니다.

## 질문

아는 것만 답해 주셔도 됩니다. 직업각인마다 다르면 따로 적어 주세요.

1. **아덴 스킬** (3단계)
   - 아덴 스킬이 스킬창 어디에 있나요? (가운데 클래스 그림의 왼쪽, 오른쪽, 또는 다른 자리)
   - 각 아덴 스킬은 어떤 방식인가요?
     - ① 쓰고 나면 재사용 대기시간만 돌아감
     - ② 대기시간이 끝나도 게이지가 모자라면 쓸 수 없음
     - ③ 여러 번 충전되어 횟수만큼 쓸 수 있음
   - 쓸 수 있을 때와 없을 때 아이콘이 어떻게 다르게 보이나요? (예: 아이콘이 어두워짐, 테두리가 생김, 키 글자 색이 바뀜)
   - 쓸 수 없는 동안에도 아이콘에 숫자(남은 시간)가 보이나요?
2. **직업각인 구분** (1단계)
   - 두 직업각인의 초각성 스킬 아이콘이 서로 비슷한가요?
   - 두 직업각인의 스킬 구성이 같은가요, 다른가요?
3. **게이지 모양** (2단계)
   - 게이지가 여러 칸으로 나뉘나요? 몇 칸인가요?
   - 채우는 중인 칸과 다 찬 칸의 색이 다른가요? 다르면 어떤 색인가요?
4. **게이지가 빛나는 때** (3단계)
   - 예: 칸이 하나 다 찰 때마다 / 몇 % 이상이고 특정 스킬이 준비됐을 때 / 빛나지 않음
5. **칸이 찰수록 게이지 색이 진해지나요?** (3단계) 진해진다면 몇 칸부터 얼마나 진해지나요?
6. **게이지를 쓰는 스킬** (3단계)
   - 어떤 스킬이 게이지를 쓰나요?
   - 얼마나 쓰나요? (예: 다 찬 칸을 최대 2개 / 50%)
7. **역할** (1단계) 각 직업각인은 딜러인가요, 서포터인가요?

## 보내는 방법

1. 폴더를 하나 만들어 아래처럼 넣어 주세요. 이름은 예시입니다.
   ```
   소서리스_점화/
     스킬창.png
     게이지_빈.png
     게이지_가득.png
     플레이영상.mp4
     답변.txt   ← 질문 답, 해상도와 HUD 크기
   ```
2. 폴더를 구글 드라이브나 원드라이브에 올리고, **링크가 있는 모든 사용자가 볼 수 있게** 공유해 주세요.
3. 링크를 GitHub 저장소의 Issues에 올리거나, 이 안내를 받은 곳으로 보내 주세요.

자료가 부족하거나 다시 찍어야 할 것이 있으면 무엇이 필요한지 따로 알려 드리겠습니다. 이름을 적어 주시면 업데이트 내용에 감사 인사로 남기겠습니다(원하지 않으면 적지 않으셔도 됩니다).
